# References — внешние справочники для агентов

> Здесь храним локальные копии внешней документации в формате, удобном для
> агентов (обычно `*-llms.txt`). Идея: справочник должен быть доступен прямо в
> репозитории, а не где-то во внешнем интернете.

## Что сюда класть

- Сжатые справочники по библиотекам/инструментам, которые реально используются.
- Файлы вида `<инструмент>-llms.txt`.

## Как использовать

- Перед использованием сторонней библиотеки сверяйся с её актуальной документацией;
  стабильную выжимку сохраняй сюда для повторного использования.
