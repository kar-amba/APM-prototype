# Design Docs — каталог

> Каталог проектных документов. Каждый документ — источник истины по своей теме.
> Колонка «Статус» показывает, насколько документ отражает реальное состояние.

## Статусы

- `draft` — черновик, обсуждается.
- `accepted` — принято, можно опираться.
- `verified` — соответствует реальному коду/поведению.
- `stale` — устарел, требует обновления.

## Правила ведения

- Новый значимый проектный документ — добавляй сюда строкой со статусом.
- Меняешь поведение системы — обнови документ и его статус.
- Не плоди пустые заглушки: документ создаём, когда есть содержание.
