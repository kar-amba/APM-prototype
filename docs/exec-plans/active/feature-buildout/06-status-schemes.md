# План: Конфигуратор статусных схем

- Статус: active
- Дата: 2026-05-31

## Цель

Наполнить раздел «Статусные схемы» (`src/features/status-schemes`) — настраиваемый
конструктор состояний и переходов, переиспользуемый разными сущностями. Это одна
из ключевых демонстрируемых возможностей. Сейчас это заглушка.

## Контекст

- Конфигурируемость схем: [`../../../product/conceptual-product.md`](../../../product/conceptual-product.md)
  (раздел «Конфигурируемость статусных схем») и
  [`../../../product/main.md`](../../../product/main.md) (раздел 4, п. 7).
- Зависит от: [`01-domain-model.md`](01-domain-model.md) (`StatusScheme`, `Status`,
  `Transition`), [`03-persistence-and-crud.md`](03-persistence-and-crud.md).

## Шаги

- [ ] Список схем + создание/копирование схемы; привязка к типу сущности
      (активы, анализы, стратегии, мероприятия, маршруты).
- [ ] Редактор состояний: добавление/переименование, цвет/семантика бейджа
      (через токены статусных цветов брендбука).
- [ ] Редактор разрешённых переходов между состояниями.
- [ ] Применение схемы: смена статуса сущности возможна только по разрешённому
      переходу (проверка в сервисе/репозитории).
- [ ] Перевести статусы активов на выбранную схему (заменить «зашитый» enum).
- [ ] i18n + визуал на токенах брендбука.
