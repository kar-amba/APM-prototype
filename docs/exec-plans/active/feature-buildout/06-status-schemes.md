- Статус: active
- Дата: 2026-05-31

## Цель

Наполнить раздел «Статусные схемы» (`src/features/status-schemes`) — настраиваемый
конструктор состояний и переходов, переиспользуемый разными сущностями. Это одна
из ключевых демонстрируемых возможностей. Сейчас это заглушка.

## Журнал решений

- 2026-06-04: создан слой сервисов `src/services/` (`status-flow.ts`) —
      `findSchemeForEntity`, `statusesOfScheme`, `transitionsOfScheme`,
      `allowedNextStatuses`, `isTransitionAllowed`. UI/репозиторий обращаются к
      нему, чтобы смена статуса уважала схему.
- 2026-06-04: enum `assetStatusSchema` НЕ удалён. Коды состояний схемы
      «Жизненный цикл актива» совпадают с enum, поэтому Реестр валидирует переход
      по схеме, но хранит статус как enum. Полная замена enum на ссылку на
      состояние схемы — крупный сквозной рефактор (модель, сиды, реестр, поиск,
      дашборд); отложена в tech-debt, чтобы не дестабилизировать фазу 1.
- 2026-06-04: смена статуса вынесена в карточку актива (`AssetDetails`) —
      выпадающий список показывает только разрешённые из текущего состояния
      переходы; недопустимые коды отфильтрованы по `assetStatusSchema`.
