# План: Наполнение демо-предприятия «ГлоуБайт-Металл»

- Статус: active
- Дата: 2026-05-31

## Цель

Расширить сиды до «живого и наполненного» демо-предприятия из продуктового видения,
чтобы при первом открытии система выглядела реалистично. Сейчас сид содержит срез:
2 цеха, несколько участков и ~18 единиц оборудования (`src/data/mock/seed.ts`).

## Контекст

- Целевой объём демо-предприятия: [`../../../product/main.md`](../../../product/main.md)
  (раздел 7): 4 цеха, ~10–15 участков, ~150–300 единиц с узлами/компонентами.
- Зависит от: [`01-domain-model.md`](01-domain-model.md) (новые сущности).
- Сиды валидируются Zod при загрузке репозиторием (`src/data/in-memory`).

## Шаги

- [ ] Достроить иерархию функциональных мест: Дробильно-обогатительный,
      Плавильно-печной, Прокатный, Энергетический цеха + участки.
- [ ] Нарастить парк оборудования до целевого объёма с узлами и компонентами
      (дробилки, грохоты, конвейеры, мельницы, флотомашины, печи, насосы,
      компрессоры, краны, вентиляция).
- [ ] Классы и атрибуты: классификатор + наборы атрибутов и значения по активам.
- [ ] Справочники: производители, оргструктура, персонал, единицы измерения.
- [ ] Статусные схемы и стартовые статусы активов; оценки критичности.
- [ ] 3–5 маршрутов обхода с точками контроля и историей замеров; несколько
      «сработавших» отклонений → дефекты.
- [ ] Разбить разросшиеся сиды на тематические файлы внутри `src/data/mock/`.
