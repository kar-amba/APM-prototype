- Статус: active
- Дата: 2026-05-31

## Цель

Наполнить раздел «Поиск активов» (`src/features/asset-search`) расширенным
фильтром по атрибутам и сохраняемыми представлениями. Сейчас это заглушка.

## Контекст

- Атрибуты фильтра: [`../../../product/main.md`](../../../product/main.md)
  (раздел 5, «Поиск активов»).
- Зависит от: [`01-domain-model.md`](01-domain-model.md) (классы/атрибуты),
  [`02-demo-seed.md`](02-demo-seed.md) (данные).
- Таблица результатов — TanStack Table (как в `asset-registry`), фильтры — Zustand.

## Шаги

- [x] Панель фильтров: идентификатор/наименование/инв./зав. номер (поиск),
      класс, функцместо (с потомками), владелец, планировщик, статус,
      критичность, производитель.

- [x] Таблица результатов (TanStack) с сортировкой и колонками статуса/
      критичности; переход в карточку актива (через `uiStore.focusAsset`).
- [x] **Сохраняемые представления**: сохранение/загрузка/удаление наборов
      фильтров (`searchStore`, zustand persist в localStorage).
- [x] Все строки — через i18n; визуал на токенах брендбука.

## Журнал решений

- 2026-06-04: фильтры — в zustand-сторе (`searchStore`), сохранённые
      представления персистятся через `persist` (`partialize` только `savedViews`);
      текущие фильтры в памяти.
- 2026-06-04: фильтр по функцместу переиспользует `collectDescendantIds` из
      `asset-registry/lib` (учитывает всю ветку).
- 2026-06-04: переход в карточку — через `uiStore.focusedAssetId`: поиск ставит
      id и навигирует на `/assets`, Реестр лениво выбирает актив при монтировании
      и сбрасывает сигнал (без `setState` в эффекте — требование eslint).
- 2026-06-04: значения производителя/владельца/планировщика в выпадающих
      списках берутся из уникальных значений активов (а не из справочников),
      чтобы фильтр гарантированно совпадал с данными.
- 2026-06-04: навигация к активу будет уточнена в фазе **1.2**
      ([`1.2-asset-card.md`](1.2-asset-card.md)): ссылка на полную карточку в новой
      вкладке; фокус из поиска — выделение строки и краткая панель в реестре.
