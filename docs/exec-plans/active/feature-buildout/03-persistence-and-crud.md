# План: Режимы хранения и интерактивный CRUD

- Статус: active
- Дата: 2026-05-31

## Цель

Сделать прототип интерактивным: добавить переключаемые режимы хранения данных и
инфраструктуру CRUD на формах. Сейчас репозиторий только in-memory; методы
`create/update/remove` — заготовки (`src/data/repository.ts`).

## Контекст

- Режимы хранения: [`../../../techstack/main.md`](../../../techstack/main.md)
  (раздел «Абстракция хранения») и [`../../../product/conceptual-product.md`](../../../product/conceptual-product.md).
- Формы: React Hook Form + Zod (уже в стеке); схемы — из
  [`01-domain-model.md`](01-domain-model.md).
- Слой репозитория абстрагирует источник — UI не меняется при смене режима.
- Дизайн форм/диалогов — обёртки `src/shared/ui` + токены брендбука.

## Шаги

- [ ] Реализовать репозиторий поверх **localStorage** (сериализация + Zod при чтении).
- [ ] Реализовать репозиторий поверх **IndexedDB через Dexie** (документацию Dexie
      сверить через Context7).
- [ ] Режим **«Сиды»** по умолчанию + действие **«Сбросить к исходному состоянию»**.
- [ ] Системная настройка выбора режима хранения (Zustand + персист настройки).
- [ ] Заготовка-интерфейс режима **«База данных»** (без реализации, как задел).
- [ ] CRUD-инфраструктура: переиспользуемые форма/диалог на RHF + Zod-resolver,
      обработка ошибок валидации, тосты/подтверждения удаления.
- [ ] Подключить CRUD к Реестру активов: создание/редактирование/удаление активов
      и функциональных мест (пилот паттерна для остальных разделов).
