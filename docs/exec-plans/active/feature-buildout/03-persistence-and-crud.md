# План: Режимы хранения и интерактивный CRUD

- Статус: completed
- Дата: 2026-05-31

## Цель

Сделать прототип интерактивным: добавить переключаемые режимы хранения данных и
инфраструктуру CRUD на формах. Сейчас репозиторий только in-memory; методы
`create/update/remove` — заготовки (`src/data/repository.ts`).

## Контекст

- Режимы хранения: [`../../../techstack/main.md`](../../../techstack/main.md)

  [`01-domain-model.md`](01-domain-model.md).

- Дизайн форм/диалогов — обёртки `src/shared/ui` + токены брендбука.
