## Журнал решений

- 2026-06-07: доменные правила вынесены в сервис `services/criticality.ts`
  (риск-балл `consequence × probability`, пороги класса по баллу:
  low ≤4 / medium 5–8 / high 9–14 / critical ≥15 — согласованы с сидами,
  `recommendedStrategyType` как подсказка для 08-strategies). UI читает данные
  через репозиторий, считает риск только через сервис.
- 2026-06-07: оценка критичности по активу хранится как единственная актуальная
  запись — повторная оценка обновляет существующий `CriticalityAssessment`
  (не плодим историю), параллельно проставляется `Asset.criticality` → класс
  виден в реестре, поиске и виджете карточки.
- 2026-06-07: матрица собрана на CSS-grid с явным позиционированием ячеек
  (строки — последствия 5→1 сверху вниз, столбцы — вероятность 1→5), зоны риска
  окрашены семантическими токенами (success/info/warning/error). `criticalityTone`
  переиспользован из `features/asset-registry/lib` как единый источник тонов.
