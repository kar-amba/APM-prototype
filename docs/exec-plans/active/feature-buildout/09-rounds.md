- Статус: active

## Цель

Наполнить раздел «Обходы и маршруты» (`src/features/rounds`) — конструктор
маршрутов, экран выполнения обхода и журнал замеров. Сейчас это заглушка.

## Контекст

- Маршруты и обходы: [`../../../product/main.md`](../../../product/main.md)
  (раздел 4, п. 5; раздел 5 — карточка, вкладка «Обходы и замеры»).
- Симулируемая «интеграция через обходы»: замер вне диапазона → дефект/уведомление
  (раздел 2, п. 6).
- Зависит от: [`01-domain-model.md`](01-domain-model.md) (`Route`, `RoutePoint`,
  `MeasurementPoint`, `RoundExecution`, `Reading`),
  [`03-persistence-and-crud.md`](03-persistence-and-crud.md).

## Шаги

- [ ] Конструктор маршрута: набор точек контроля (замеры/чек-листы) с допустимыми
      диапазонами; привязка к активам/функцместам.
- [ ] Экран выполнения обхода (мобильно-подобный): ввод замеров по точкам.
- [ ] Валидация замера: значение вне диапазона помечается отклонением и **порождает
      дефект/уведомление** (общий сервис с симулятором, см. [`10-telemetry-simulation.md`](10-telemetry-simulation.md)).
- [ ] Журнал замеров и история по точкам; отображение на вкладке «Обходы и замеры»
      карточки актива (тренды — Recharts).
- [ ] i18n + визуал на токенах брендбука.
