# План: Роли и акценты интерфейса

- Статус: completed
- Дата: 2026-05-31 (завершено 2026-06-08)

## Цель

Сделать переключатель роли содержательным: смена роли меняет акценты интерфейса
(стартовый раздел, состав виджетов, доступные действия). Сейчас переключатель роли
есть в оболочке (`uiStore`), но на интерфейс почти не влияет. Это демонстрационный
механизм, **не** реальная система прав.

## Журнал решений

- 2026-06-08: профили ролей вынесены в `services/role-profiles.ts` (стартовый
  раздел, видимость KPI/графиков/виджетов дашборда, акцентные пути навигации,
  вкладка обходов по умолчанию, ключи контекстных подсказок разделов). Доступ из UI
  — `hooks/useRoleProfile.ts`.
- 2026-06-08: глобальный баннер `app/RoleAccentBanner` в `AppShell` поясняет фокус
  роли и ведёт к `homePath`; смена роли в селекторе делает `navigate(homePath)`.
  Приоритетные пункты sidebar подсвечиваются (`menuItemAccent`), доступ ко всем
  разделам сохранён.
- 2026-06-08: дашборд фильтрует KPI, графики и виджеты по роли; акцентные плитки/
  панели выделяются рамкой (`kpiCardAccent`, `paneAccent`). Оператор видит только
  отклонения и обходы; руководитель — полный набор.
- 2026-06-08: `SectionRoleHint` показывает контекстную подсказку в разделах
  assets/strategies/criticality/rounds/dashboard. Для оператора экран выполнения
  обхода получает акцентную обводку (`executionLayoutAccent`); при смене роли
  вкладка обходов переключается на значение из профиля (`execution` для оператора).
