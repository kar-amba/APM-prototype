# План: Роли и акценты интерфейса

- Статус: active
- Дата: 2026-05-31

## Цель

Сделать переключатель роли содержательным: смена роли меняет акценты интерфейса
(стартовый раздел, состав виджетов, доступные действия). Сейчас переключатель роли
есть в оболочке (`uiStore`), но на интерфейс почти не влияет. Это демонстрационный
механизм, **не** реальная система прав.

## Контекст

- Роли и их акценты: [`../../../product/main.md`](../../../product/main.md)
  (раздел 3) и [`../../../product/conceptual-product.md`](../../../product/conceptual-product.md)
  (раздел «Переключатель ролей»).
- Текущее состояние роли: `src/store/uiStore.ts`.
- Выполняется поверх готовых разделов, поэтому идёт в конце.

## Шаги

- [ ] Описать профили ролей: Инженер по надёжности, Планировщик ТОиР, Оператор,
      Руководитель — стартовый раздел, набор виджетов дашборда, акцентные действия.
- [ ] Стартовый раздел при выборе роли (редирект/подсветка в навигации).
- [ ] Акценты на дашборде и в разделах (что показываем/выделяем для роли).
- [ ] Роль «Оператор» → акцент на выполнение обходов (мобильно-подобный экран).
- [ ] i18n названий ролей и подписей.
