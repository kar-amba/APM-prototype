# План: Каркас прототипа + вертикальный срез «Реестр активов»

- Статус: active
- Дата: 2026-05-31

## Цель

Создать первый scaffold прототипа APM ГлоуБайт: рабочее приложение на Vite +
React 19 + TS с оболочкой (sidebar, верхняя панель, переключатель роли),
маршрутами на все 8 разделов, токенами дизайн-системы и i18n, плюс один сквозной
вертикальный срез — Реестр активов в паттерне «дерево + таблица + детали» на
мок-данных через слой репозитория.

## Журнал решений

- 2026-05-31: pnpm запускается через `corepack pnpm@<версия>` — глобальный shim
  не ставится (нет прав на запись в `Program Files`).
- 2026-05-31: версии библиотек сверены через npm-реестр; `@eslint/js`
  зафиксирован на `^10.0.1` (последний на момент скаффолда).
- 2026-05-31: в `tsconfig` убран `baseUrl` (deprecated в TS 6); алиас `@/*`
  работает через `paths` без `baseUrl`.
- 2026-05-31: режим хранения данных в v1 — только in-memory (сиды); localStorage
  / Dexie / БД оставлены как задел в слое репозитория.
- 2026-05-31: вкладки карточки актива сбрасываются на «Обзор» при смене актива
  через `key` (remount), без `setState` в эффекте.
