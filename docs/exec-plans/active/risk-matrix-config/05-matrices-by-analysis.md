# План 05: Матрицы по видам анализа

- Статус: active
- Дата: 2026-06-08

## Цель

Дать UI для управления **самими матрицами риска** под виды анализа ACA, FMECA,
RCM, RBI и управление стратегиями: создание/копирование матрицы, выбор вида
анализа, привязка осей (шкалы вероятности и последствий), режим ранга и агрегации
категорий, назначение матрицы по умолчанию, интерактивный предпросмотр сетки.
Это «сборочный» экран, объединяющий шкалы (план 02), категории (план 03) и
зоны (план 04).

## Контекст

- `RiskMatrix` и связи: [`01-domain-model.md`](01-domain-model.md).
- Сервис правил `src/services/risk-matrix.ts` (риск-балл, зона ячейки, валидация
  зон) — из [`04-risk-levels-zones.md`](04-risk-levels-zones.md).
- Вкладка «Матрицы» раздела «Матрицы риска».
- Виды анализа (ACA/FMECA/RCM/RBI/стратегии) и их смысл — см. [`index.md`](index.md).
- Существующая интерактивная сетка-референс: `src/features/criticality/CriticalityMatrix.tsx`
  (CSS-grid, клик по ячейке → фильтр) — переиспользовать визуальный приём.

## Шаги

- [ ] Список матриц, сгруппированный по `analysisType`; бейдж «по умолчанию» и
      переключатель матрицы по умолчанию (ровно одна `isDefault` на вид анализа —
      назначение новой снимает флаг с предыдущей).
- [ ] Форма матрицы (`RiskMatrixForm`, RHF + Zod):
      - `code`, `name`, `description`, `analysisType`;
      - выбор `probabilityScaleId` (kind='probability') и `consequenceScaleId`
        (kind='consequence');
      - `rankMode` (product/sum/explicit) и `consequenceAggregation` (max/weighted);
      - встроенные секции — редактор зон (план 04) и (для explicit) назначение
        ячеек.
- [ ] Интерактивный предпросмотр сетки (`RiskMatrixPreview`): оси из выбранных шкал
      (подписи уровней по `label`/`anchor`), каждая ячейка окрашена по
      `riskLevelForCell` из сервиса; наведение показывает балл и зону; в режиме
      explicit клик назначает зону (логика из плана 04).
- [ ] Копирование матрицы как шаблона (для быстрого создания похожей под другой вид
      анализа) — глубокое копирование встроенных коллекций с новым `id`/`code`.
- [ ] Валидация: для `explicit` все ячейки назначены; оси — шкалы корректного вида;
      зоны валидны (`validateZones`); уникальность `code`.
- [ ] Операции через `useRepository('riskMatrices')` + `bumpRevision`.
- [ ] i18n (`riskConfig.matrices.*`, `riskAnalysisType.*`) + визуал на токенах.

## Критерии готовности

- [ ] Можно создавать/копировать/удалять матрицы и привязывать их к видам анализа.
- [ ] У каждого вида анализа ровно одна матрица по умолчанию.
- [ ] Предпросмотр сетки корректно окрашивается для product/sum/explicit.
- [ ] `npm run lint` и `npm run build` проходят.
