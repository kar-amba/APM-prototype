# Exec Plans — планы работ

> Планы — артефакты первого класса. Они версионируются вместе с кодом, чтобы
> агенты могли работать без внешнего контекста.

## Как это устроено

- `active/` — планы в работе.
- `completed/` — завершённые планы (переносим сюда по готовности).
- `tech-debt-tracker.md` — известный технический долг.

## Текущие планы

- `active/skeleton-scaffold.md` — каркас прототипа + срез «Реестр активов».
- `active/feature-buildout/index.md` — **дорожная карта обвязки каркаса**
  (наращивание остальных разделов, CRUD, режимы хранения, симулятор) + лёгкие
  планы по каждому рабочему блоку.
- `active/feature-buildout/1.1-phase1-tech-debt.md` — **фаза 1.1**: реализация
  техдолга фазы 1 (перед фазой 2).
- `active/feature-buildout/1.2-asset-card.md` — **фаза 1.2**: проработка карточки
  активов (краткая панель в реестре, полная карточка в новой вкладке, виджеты).

## Когда заводить план

- **Лёгкий план** — для небольшого изменения: цель + чек-лист шагов.
- **Полноценный план** — для сложной работы: контекст, шаги, журнал решений,
  критерии готовности, прогресс.

## Шаблон плана

Создавай файл `active/<краткое-имя>.md` по шаблону:

```markdown
# План: <название>

- Статус: active | completed
- Дата: YYYY-MM-DD

## Цель
Что и зачем делаем (ожидаемый результат).

## Контекст
Ссылки на документы/код, ограничения.

## Шаги
- [ ] Шаг 1
- [ ] Шаг 2

## Журнал решений
- YYYY-MM-DD: приняли решение X, потому что Y.

## Критерии готовности
Когда считаем задачу выполненной.
```
